Editor notes / Cursor

Let the codebase be the context window.

Cursor’s advantage is less about generating a clever snippet and more about asking questions across a project. Start with a bounded change, inspect the files it touched, and keep your existing tests in the loop. For migrations and unfamiliar code, ask it to map the path before asking it to edit.

Workflow · 8 minute read
Pairing notes / GitHub Copilot

Small suggestions. Deliberate acceptance.

Inline completion shines when the surrounding code already expresses intent: a well-named function, a nearby example, a clear test. Treat generated code as a proposal. Accept in slices, read the whole function, and use chat for explanation or exploration rather than handing over an ambiguous task.

Workflow · 6 minute read
Engineering habits / Review

The review checklist still belongs to you.

AI can make a diff arrive faster without making it easier to trust. Check behavior at boundaries, error handling, security assumptions, and whether the change fits the shape of the system. A useful prompt asks for risks; a useful review verifies them.
